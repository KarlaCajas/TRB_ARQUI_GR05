🌐 ESTADOS DE CONEXIÓN
────────────────────────────────────────────────────────────────

CON SERVIDOR DISPONIBLE:
  Estado: ✅ Conectado al servidor
  - Conversiones se calculan Y se guardan
  - Cada conversión crea un registro en la BD
  - Indicador verde

SIN SERVIDOR (OFFLINE):
  Estado: ⚠️ Servidor no disponible (modo offline)
  - Conversiones se calculan localmente
  - NO se guardan en el servidor
  - Indicador naranja
  - La calculadora funciona normal

DESPUÉS DE GUARDAR:
  Estado: ✅ Guardado en servidor
  - Confirmación de guardado exitoso
  - Indicador verde

ERROR AL GUARDAR:
  Estado: ⚠️ No se pudo guardar
  - La conversión se calculó bien
  - Error temporal con el servidor
  - Indicador naranja

────────────────────────────────────────────────────────────────
📊 DATOS GUARDADOS EN EL SERVIDOR
────────────────────────────────────────────────────────────────

Cada conversión realizada guarda:

{
  "tipoConversion": "Temperatura - Celsius a Fahrenheit",
  "unidadOrigen": "Fahrenheit",
  "unidadDestino": "",
  "factorConversion": 2.8,
  "descripcion": "Conversión realizada por MONSTER: 25 °C = 77.00 °F"
}

Endpoint: POST http://localhost:5014/api/ConversionUnidades_Controlador

🚀 CÓMO EJECUTAR
────────────────────────────────────────────────────────────────

CON SERVIDOR (Recomendado):
  1. Inicia el servidor REST .NET en localhost:5014
  2. python app.py
  3. Las conversiones se guardarán automáticamente

SIN SERVIDOR (Modo Offline):
  1. python app.py
  2. La app detecta que no hay servidor
  3. Funciona como calculadora local
  4. Conversiones NO se guardan
