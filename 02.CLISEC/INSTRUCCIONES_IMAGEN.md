# Instrucciones para la Imagen de Sullivan

## Ubicación de la imagen

Para que aparezca la imagen de Sullivan en el login, debes colocar el archivo de imagen en esta ubicación:

```
02.CLISEC/login-solivan.jpeg
```

## Pasos:

1. Copia el archivo `login-solivan.jpeg` que te proporcionaron
2. Pégalo directamente en la carpeta `02.CLISEC`
3. Asegúrate de que el nombre sea exactamente: `login-solivan.jpeg`

## Si no tienes la imagen:

El programa funcionará igual y mostrará un placeholder con el emoji 🎓 y el texto "SULLIVAN".

cd "c:\ARQUITECTURA\TI1.2 SOAP_DOTNET_SINBDD_GRO#5\02.CLISEC"
